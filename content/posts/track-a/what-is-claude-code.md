## Claude Code가 뭔가요?

Claude Code는 Anthropic이 만든 **AI 기반 CLI(명령줄 인터페이스) 도구**예요. 쉽게 말하면, 터미널 안에서 Claude AI와 대화하면서 코드를 작성하고, 파일을 수정하고, 명령까지 실행할 수 있는 개발 도우미입니다.

비유를 들어볼게요. 일반 AI 챗봇(Claude.ai, ChatGPT 등)이 **"카페 직원"** 이라면 — 손님이 말하면 답변을 건네주는 역할 — Claude Code는 **"현장 팀원"** 에 가깝습니다. 직접 컴퓨터 앞에 앉아서 파일을 열고, 코드를 고치고, 결과를 확인해가며 실제로 일을 처리해줘요.

---

## 일반 AI 챗봇과 무엇이 다른가요?

![일반 AI 챗봇과 Claude Code의 차이점 비교 표](https://dmazone.github.io/blogauto/images/what-is-claude-code-02.webp)

| 비교 항목 | 일반 AI 챗봇 | Claude Code |
|-----------|:-----------:|:-----------:|
| 실행 환경 | 웹 브라우저 | 터미널(CLI) |
| 파일 직접 읽기·수정 | 불가 | 가능 |
| 코드 실행 | 불가 | 가능 |
| 작업 자동화 | 불가 | 가능 |

일반 AI에게 "이 코드 고쳐줘"라고 하면 텍스트로 수정된 코드를 돌려줍니다. 복사해서 에디터에 직접 붙여넣어야 하죠. Claude Code는 달라요. 파일을 직접 열고, 수정하고, 저장까지 해줍니다. 터미널 명령어도 대신 실행해줘요.

---

## Claude Code로 무엇을 할 수 있나요?

실제로 Claude Code를 사용하면 이런 것들이 가능해요.

- **코드 작성·수정·디버깅** — "이 함수에서 에러 나는 이유 찾아줘"라고 말하면 직접 원인을 찾아 고쳐줍니다
- **파일·폴더 자동화** — 디렉토리 구조 생성, 파일 이름 일괄 변경 등을 한 번에 처리
- **Git 작업** — 커밋 메시지 작성, PR 설명 초안 생성, 변경 이력 요약
- **문서·블로그 작성** — 이 블로그처럼 Hugo 포스팅도 자동으로 생성
- **MCP 연동** — GitHub, Google Drive 같은 외부 서비스와 연결해 더 큰 자동화 구현

터미널에서 이렇게 시작할 수 있어요.

```bash
# 현재 폴더의 파이썬 파일 전체를 분석하고 개선안 제안
claude "이 프로젝트의 코드 품질 문제점을 찾아서 수정해줘"
```

한 줄 명령으로 Claude가 프로젝트 파일을 직접 읽고 분석한 뒤, 수정까지 진행합니다.
